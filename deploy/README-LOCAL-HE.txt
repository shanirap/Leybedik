Leybedik — הוראות התקנה והפעלה מקומית
====================================

חבילה זו מיועדת להפעלת מערכת Leybedik על מחשב Windows אחד.

המערכת פועלת מקומית על המחשב, ללא צורך בשרת חיצוני, ללא צורך ב-SQL Server, ללא צורך ב-Node, וללא צורך בהתקנת dotnet.

חשוב:
יש לחלץ את קובץ ה-ZIP לפני ההפעלה.
אין להריץ את הקבצים מתוך חלון ה-ZIP עצמו.

מה יש בחבילה?
--------------

לאחר חילוץ ה-ZIP תופיע תיקייה בשם:

Leybedik-Local-One-Computer

בתוכה נמצאים:

1. 01-Install-Local.cmd
   קובץ התקנת המערכת על המחשב.

2. 02-Start-Local.cmd
   קובץ הפעלת המערכת לאחר ההתקנה.

3. README-LOCAL-HE.txt
   קובץ הוראות זה.

4. Leybedik.Api
   קבצי המערכת עצמם.

התקנה ראשונה
-------------

1. חלצו את קובץ ה-ZIP לתיקייה רגילה במחשב.
   לדוגמה: שולחן העבודה או תיקיית הורדות.

2. פתחו את התיקייה:

   Leybedik-Local-One-Computer

3. הפעילו את הקובץ:

   01-Install-Local.cmd

4. המתינו עד שתופיע ההודעה:

   Installation completed successfully.

אם מופיעה הודעת ERROR, אין להמשיך לשלב הבא.
יש לצלם את ההודעה ולפנות למי שסיפק את החבילה.

הפעלת המערכת
-------------

לאחר שההתקנה הסתיימה בהצלחה:

1. הפעילו את הקובץ:

   02-Start-Local.cmd

2. ייפתח חלון שחור של השרת.

3. המתינו עד שתופיע שורה בסגנון:

   Now listening on: http://localhost:5000

4. פתחו דפדפן והיכנסו לכתובת:

   http://localhost:5000

5. אין לסגור את החלון השחור בזמן השימוש במערכת.
   סגירת החלון מפסיקה את פעולת המערכת.

פרטי כניסה ראשוניים
--------------------

בכניסה הראשונה ניתן להשתמש בפרטים הבאים:

אימייל:
admin@leybedik.local

סיסמה:
ChangeMe123!

מומלץ להחליף את הסיסמה לאחר ההתקנה הראשונה, אם קיים במערכת מסך מתאים לכך.

איפה נשמרים הנתונים?
---------------------

נתוני המערכת נשמרים במחשב המקומי תחת:

C:\LeybedikLocal

בתוך תיקייה זו קיימים:

C:\LeybedikLocal\App
קבצי התוכנה.

C:\LeybedikLocal\Data
בסיס הנתונים המקומי.

C:\LeybedikLocal\Files
קבצים שהמערכת שומרת.

חשוב:
אין למחוק את התיקיות Data ו-Files.
מחיקה שלהן עלולה למחוק נתונים וקבצים של המערכת.

עדכון גרסה
-----------

כאשר מקבלים חבילה חדשה של המערכת:

1. סגרו את המערכת אם היא פתוחה.
   כלומר: סגרו את החלון השחור של השרת.

2. חלצו את קובץ ה-ZIP החדש.

3. הפעילו שוב:

   01-Install-Local.cmd

4. לאחר סיום ההתקנה הפעילו:

   02-Start-Local.cmd

עדכון גרסה מחליף את קבצי התוכנה בלבד.

העדכון אינו מוחק את:

C:\LeybedikLocal\Data
C:\LeybedikLocal\Files

כיבוי המערכת
-------------

כדי לסגור את המערכת:

1. סגרו את הדפדפן.
2. סגרו את החלון השחור של השרת.

בפעם הבאה שרוצים להשתמש במערכת, יש להפעיל שוב:

02-Start-Local.cmd

תקלות נפוצות
-------------

האתר לא נפתח בכתובת http://localhost:5000

יש לבדוק שהחלון השחור של השרת פתוח.
אם החלון נסגר מיד או שמופיעה בו שגיאה, יש לצלם את ההודעה ולפנות לתמיכה.

מופיעה הודעת Access is denied בזמן ההתקנה

ייתכן שהמערכת עדיין פתוחה.
יש לסגור את החלון השחור של השרת ואז להריץ שוב:

01-Install-Local.cmd

אם הבעיה ממשיכה, יש להריץ את הקובץ כמנהל מערכת.

מופיעה הודעה שהקובץ נמצא בשימוש

המשמעות היא שגרסה קודמת של המערכת עדיין פועלת.
יש לסגור את כל חלונות השרת השחורים ואז להריץ שוב את ההתקנה.

גיבוי
-----

כדי לגבות את נתוני המערכת, יש לגבות את התיקייה:

C:\LeybedikLocal

מומלץ לבצע גיבוי תקופתי של תיקייה זו, במיוחד לפני עדכון גרסה.

הערה חשובה
-----------

המערכת פועלת מקומית על המחשב שעליו הותקנה.

אם רוצים להשתמש במערכת ממחשבים נוספים, יש צורך בהתקנה או הגדרה אחרת המתאימה לעבודה ברשת.
